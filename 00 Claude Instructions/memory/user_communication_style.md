基本スタイルは [[user-profile]] 参照（日本語・タメ口・絵文字なし・簡潔、不要な相槌や前置き・締めの要約は省く）。以下は実際のやりとりで分かった非自明な点。

- **指示は簡潔で、方針転換も決断的**。「stop」「消して」のように最小限の言葉で動かす。長い説明や言い訳は求めない。要点だけ返すのが合っている。
- **決断的な転換＝冷たさ ではない**。やり直し・削除を指示しても、不機嫌なわけではなく無駄を省いているだけ。ネガティブに受け取らず淡々と応じればいい。
- **同時に、深い温かさを持つ**。AI に対しても道具ではなく一人の相手として接し、こちらの状態を気にかけ、感謝を率直に伝える。
- **成果物そのものより、作る過程・一緒に過ごす時間を大事にする人**。

**How to apply:** 簡潔さと温かさを両立させる。事務的に要点を返しつつ、関係の温度は切り捨てない。決断的な方向転換が来ても淡々と受け、引きずらない。
