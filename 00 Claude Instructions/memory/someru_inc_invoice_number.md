## How to apply
- 請求書・領収書・契約書・PDFインボイス等、適格請求書として発行する全書類に記載必須
- Stripe ダッシュボードの「税ID」設定にこの番号を登録すると、Stripe発行の領収書PDFにも自動記載される
- Notion / Apps Script から領収書を自動生成する場合も、テンプレートに `T6011001142353` を埋め込む
