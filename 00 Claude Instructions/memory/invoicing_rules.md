# 染める株式会社 請求業務ルール（Money Forward クラウド請求書）

## 着手金（請求書）の基本ルール
- **着手金は見積書総額の 50%**（=半額前金、残額は納品後請求）
- これがデフォルト。例外がない限り常に 50%。

## 例外
- **ホタルの案件のみ「トリッキーな処理」が必要**
  - 詳細はユーザーに毎回確認（標準50%ではない、特殊な計算が入る案件）

## 一般的な請求書作成の手順
1. Money Forward クラウド請求書（https://invoice.moneyforward.com/）にログイン
2. 見積書がある場合はそれをベースに請求書化
3. 取引先マスタ未登録なら新規登録（取引先名/カナ/住所/TEL）
4. 振込先は既定（三井住友銀行 渋谷駅前支店(234) 普通5395693 ソメル(カ）
5. 件名/明細を入力 → 詳細設定で外税/内税を選択 → 保存（下書き）

## 税の扱い
- ユーザーが「(税込)」と明示 → 内税モード
- 明示なし → 外税（Money Forward デフォルト）

## 請求書の送付
- メール送信は「実世界への通信」として自動承認されない
- 必ずユーザーに送信操作をしてもらうか、明示の許可を得る
