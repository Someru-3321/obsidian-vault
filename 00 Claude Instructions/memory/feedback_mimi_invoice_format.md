mi-mi+ 衣装レンタルの請求書（マネーフォワード クラウド請求書）を作るとき：

- **品目** は固定で `衣装レンタル代として` のみ。衣装名を品目に入れない。
- **詳細** に「衣装名 / レンタル期間 / 配送方法」を **3行に改行して** 入れる:
  ```
  ギンガムリボン（ロイヤルブルー）
  2026/05/23 → 2026/05/25
  郵送にてお届け→郵送にて返却
  ```
- 配送時間（例: 18:00～20:00）は **詳細に書かない**。日にちだけ。
- 郵送代は別行で `郵送代として / 1,200円 × 1`
- **明細表示列**: 帳票設定（詳細設定）で `納品日` と `単位` 列は非表示にする。表示するのは 品目／単価／数量／税率／詳細 のみ。

**Why:** ユーザから複数回修正指示。品目に詰め込みすぎ→詳細に分割→衣装名も詳細→改行で見やすく、と段階的に整理された。納品日・単位は mi-mi+ レンタル請求書では使わない情報なので非表示。

**How to apply:** 新規 mi-mi+ 請求書を作るとき、品目は `衣装レンタル代として` で固定、詳細に「衣装名／期間（時間なし）／配送方法」を3行改行で書く。納品日・単位列を表示する設定は事前にオフにしておく。
