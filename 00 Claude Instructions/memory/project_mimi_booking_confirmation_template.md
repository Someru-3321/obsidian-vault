mi-mi+ 衣装レンタルの新規予約問い合わせに対する**初回確認返信**のテンプレ。
予約フォーム/LINEで予約希望が届いたら、空き確認したうえで下記テンプレに情報を埋めて送る。

## 使い方

- 「🫵🏻様」→ お客様の名字 + 様
- ●商品名 → 衣装シリーズ+カラー (例: ギンガムリボン パープル)
- レンタル期間 → 受取日 〜 返却日
- 時間指定 → お客様の希望時間（例: 19:00〜21:00）
- 決済方法 → 「クレジットカード決済」or 「銀行振込」だけ残す（両方残すパターンもある）
- 末尾「mi-mi +」は固定

## テンプレ本文（このままLINEに貼る）

```
🫵🏻様

この度はお問い合わせいただきまして、誠にありがとうございます🎀
注文内容にお間違いのないよう、ご確認をお願いしたく、ご連絡いたしました🫧

୨୧𓐄 𓐄 𓐄 𓐄 𓐄 𓐄 𓐄 𓐄 𓐄 𓐄 𓐄 𓐄 ୨୧

●商品名


●レンタルプラン
┗通常レンタルプラン( 2泊3日)

●レンタル期間
┗  お届け〜 中のご返却必須

●受渡方法
┗ 郵送にてお届け→郵送にてご返却
時間指定：
※月曜日は定休日の為、お渡し不可

●決済方法
┗ クレジットカード決済 / 銀行振込

୨୧𓐄 𓐄 𓐄 𓐄 𓐄 𓐄 𓐄 𓐄 𓐄 𓐄 𓐄 𓐄 ୨୧

上記の内容でお間違いございませんでしょうか？
ご確認いただき、お手隙の際にご返信いただきたく思います📮

ご返信をいただき次第、同意書と請求書をメールにてお送りいたします🎀
なお、同意書と請求書のご送付には1〜2日程度お時間を頂戴する場合がございますので、あらかじめご了承ください。

ご質問等ございましたら、どうぞお気軽にご連絡くださいませ！
引き続きどうぞよろしくお願いいたします🫧

mi-mi +
```

## 注意点

- 絵文字（🎀🫧📮）と区切り記号（୨୧𓐄）は元テンプレのまま残す（mi-mi+ のブランドトーン）
- お客様の確認返信が来てから 同意書・請求書 発行 → 「契約ご送付待ち」ステータスへ
- 同意書・請求書の送付には1〜2日かかる旨を必ず明示
- 月曜日定休の文言は必ず残す
- **Notion 出入管理表 登録時は必ず「レンタル衣装(決定)」リレーション(collection://e27e3068-567b-4f82-a033-a9e5ec92524e)を追加すること**（カラー rollup や All(衣装別)ビューが動かなくなるため）。衣装ページIDを `mcp__notion-search` で `<シリーズ名>(<カラー>)` クエリして取得し、URL形式でセット。
