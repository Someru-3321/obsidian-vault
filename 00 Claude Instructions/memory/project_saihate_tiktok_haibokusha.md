## ⚠ 技術的な罠と確定手順(2026-06-22に実証)
- **動画ファイルの取り込みは自動化不可 → ユーザー手動**。理由: ① Chrome MCP `file_upload` は合計10MB上限(動画は13〜623MBで全滅)、② `request_directory` はこのセッションでも「unavailable in unsupervised mode」で弾かれた、③ computer-useはChromeが「read」階層でクリック/入力ブロック(ネイティブ選択ダイアログ操作も規約上禁止)。
- **確定フロー**: (a) MCPでアップロードタブを開く、(b) `write_clipboard` に対象動画のフルパスを入れる、(c) ユーザーに「動画を選択」→ファイルダイアログで **⌘⇧G → ⌘V → Enter → Enter** をやってもらう(⌘Vでパスがピンポイントで入り、紛らわしいファイル名の取り違えを防げる)、(d) 取り込み後はキャプション/タグ/予約日時/投稿を全部MCPで操作。
- **アカウント**: @saihate_idol は「仕事用」Chromeプロフィールにログイン(別プロフィールには個人垢 @yukik_ba がいる=誤爆注意)。再接続のたび Chrome MCP の deviceId は変わるので、`switch_browser` で確認画面を出し、**ユーザーに @saihate_idol の TikTok Studio ウィンドウで「Connect」を押してもらう**のが確実。MCPで作る新規タブ(別ウィンドウ)を使い、ユーザーはそのタブをアクティブにしてからファイル選択する。
- **時刻ピッカーの罠**: 上方向に開くので時刻フィールドを画面下部に置いてから開く。ホイールスクロールはページごと動くので、**分の列の一番上の値をクリック→中央に来て上側の値が出る、を繰り返して00まで歩く**のが確実。
- TikTokの予約は **今日から最大10日先まで**(例: 6/22なら7/2まで)。10日超は枠が開く日に追って予約。
- 既存予約で埋まっている日は飛ばす(6/23〜26は既存リリースツアー投稿で埋まっていた)。著作権チェックは「問題なし」=ミュートされない。
