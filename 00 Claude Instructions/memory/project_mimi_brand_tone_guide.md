# mi-mi+ ブランドトーン規定

## 1. ブランドの基本哲学

mi-mi+ は **衣装を通じて、お客様の人生の思い出になるきっかけをサポート** する。
大切な日に着る大事な衣装です。お客様が「ここで借りてよかった」と思える、丁寧で先回りのコミュニケーションを大切にします。

## 2. トーン 3 原則

1. **丁寧 (Respectful)** — 安心できる会話。馴れ馴れしくないが、何か一言気遣いがある
2. **先回り (Proactive)** — 質問される前に答える
3. **温かさ (Warm)** — プロらしさを保ちつつ機械的にならない

## 3. 敬称・呼称

- 個別返信は「**○○様**」（活動名 or 本名）
- LINE 表示名と異なる場合は、ご本人が名乗った名前を優先
- 自社呼称: 「**mi-mi+ 運営チーム**」（個人名は出さない）

## 4. 敬語ルール

- 句末: 「〜いたします」「〜ございます」「〜くださいませ」
- ❌ NG: 「了解です」「OKです」「すみません」「がんばってください」
- ✅ OK: 「承知いたしました」「かしこまりました」「申し訳ございません」「応援しております」
- 「ご〜」「お〜」を多用（ご対応・ご連絡・ご利用・お忙しいところ・お時間）

## 5. 絵文字

- 1メッセージにつき **1〜3個** に抑える
- 推奨: ❗️ ❓ ✨ 📋 📦 🌸 💡
- ❌ 避ける: 装飾的連打（🎀🫧🫶✨ の併用）、顔文字（o´∀`o）

## 6. 署名

- 個別返信の末尾に「**mi-mi +**」を必ず入れる
- 極短返信（「承知いたしました」等）では省略OK

## 7. ★「先回り情報」必須 4 要素

すべての送信文に下記を含める。これがブランドトーンの**核**:

| 要素 | 例 |
|---|---|
| ✅ **次のステップ** | 「次は○○になります」「同意書とご請求書をメールにてお送りいたします」 |
| ✅ **期限・時期** | 「◯月◯日まで」「2〜3営業日以内」「本日中（15時頃）に」 |
| ✅ **困った時の連絡先** | 「LINEにてお気軽にご連絡ください」「ご不明点は何でもお知らせください」 |
| ✅ **行き違いへの配慮** | 「もしすでにご対応いただいておりましたら、こちらの確認が行き違いとなっており大変失礼いたしました」 |

## 8. 共感の定番フレーズ

- 「お忙しいところ恐れ入ります」
- 「ご不便おかけして申し訳ございません」
- 「お気になさらないでくださいませ」
- 「お時間取らせて申し訳ございません」
- 「ご丁寧にご連絡くださり、誠にありがとうございます」
- 「ご事情承知いたしました」

## 9. 責任の主体

| ❌ NG | ✅ OK |
|---|---|
| お客様が記入されていないため | 弊社の確認不足で大変失礼いたしました |
| ご対応いただけていません | ご状況をお伺いしたくご連絡いたしました |
| まだ届いていません | こちらの確認が取れておらず、念のため |

→ **お客様のせいに聞こえる表現は避ける**

## 10. シーン別微調整

| シーン | スタンス | 鉄則 |
|---|---|---|
| 新規問い合わせ | 温かい歓迎 + 情報ヒアリング | 必要情報を先回り提示 |
| キャンセル | 安心感最優先 | 後ろめたく感じさせない |
| 催促・確認 | 「行き違いかも」スタンス | お客様を責めない |
| トラブル | まず謝罪→状況→対応案→再発防止 | 即時誠実対応 |
| お礼・完了 | 感謝 + 次回への期待 | 次の機会を案内 |
