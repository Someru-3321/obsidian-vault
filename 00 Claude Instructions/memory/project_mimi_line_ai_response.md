# mi-mi+ LINE 応答設定

## 設計方針 (2026-05-28 確定)

LINE公式アカウントの「AI応答(旧:AIチャットボット β)」は **使わない**。
理由: お客様の感謝メッセージやスタンプに対して「適切な回答が見つかりませんでした。ほかの聞き方をお試しください。」と返してしまい、顧客体験を著しく損なう。

代わりに **応答時間** 機能で時間帯を分け、Apps Script Webhook と固定文応答メッセージで運用する。

## 現在の設定 (LINE Official Account Manager)

### 応答機能
- **チャット**: ON
- **あいさつメッセージ**: ON (友だち追加時)
- **Webhook**: ON ✅ (Apps Script が処理。リッチメニュー postback、予約フォーム、入金/返送通知など)

### 応答時間設定 (chat.line.biz)
- タイムゾーン: Asia/Tokyo
- 火-土: **11:00 - 21:00**
- 日・月・祝日: 休業 (応答時間外扱い)

### 応答方法
- **応答時間内**: 「**手動チャット**」のみ
  - AI応答も応答メッセージも動かない
  - Webhook (Apps Script) は応答機能セクションでON なので別レイヤーで動作する
  - スタッフが手動チャット画面で必要に応じて返信
- **応答時間外**: 「**応答メッセージ**」のみ
  - AI応答は動かない
  - 「ベースの連絡」(一律応答) が全受信メッセージに対して返る

## 一律応答テンプレ「ベースの連絡」

応答メッセージ管理 (autoresponse) の `タイトル: ベースの連絡` (応答タイプ: 一律応答)。
プレビュー内容:

```
【友だちの表示名】様

この度は mi-mi+ へのご連絡ありがとうございます🙇
お問い合わせ内容を確認後、担当者より順次ご連絡いたしますので、少々お待ちください🌸

-営業日-
火〜土 11:00~21:00
日〜月 定休日

※順次対応しているため、ご返信までお時間をいただく可能性がございます。
※お急ぎの内容に関しましては営業時間外でも対応可能な場合がございます。
お気軽にご連絡ください。
```

メッセージの営業日表記 (11:00~21:00) は応答時間設定 (11:00-21:00) と一致済み。

## 経緯

- **2026-05-23**: 「予約後のお客様メッセージに AIチャットボットが反応して "適切な回答が見つかりませんでした" を返す」問題が初めて発生。Claude が原因を特定 (LINE Manager の応答設定問題で、Apps Script 側では制御不可)。設定変更手順をユーザーに案内するが、ユーザーは対応せず。

  - 応答時間外: 「応答メッセージ＋AIチャットボット(β)」→ **「応答メッセージ」のみ**
