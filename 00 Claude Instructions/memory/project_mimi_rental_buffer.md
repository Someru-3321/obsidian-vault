mi-mi+ 衣装レンタルで新規予約を Notion「出入管理表【mi-mi +】」(collection://65072907-b89f-41a9-98d7-4aeeacfe0322) に入力するときの標準ルール。

- 受取希望日 = レンタル開始日
- レンタル期間は **基本 2泊3日** (例: 5/29 受取 → 5/29〜5/31)
- 予約の **前後2日ずつをバッファ**として空けておく想定 (洗濯・点検・出荷準備)
- よって空き判定では「レンタル期間 ± 2日」の範囲で同じ衣装(カラー)に既存予約がないか確認する

**Why:** 衣装は1点物のため、返却 → クリーニング → 次回出荷の物理的な前後ギャップが必要。これを満たさないと次の利用者の納期が守れない。

**How to apply:**
- 新規予約フォームを受けたら、希望日から `[start-2日, end+2日]` の範囲で同じシリーズ&カラーの衣装の既存予約を検索
- 重複があればユーザーに報告 → 別日提案 or 別カラー提案
- 重複がなければレコード作成へ進む
- 「通常レンタルプラン」= 2泊3日。「5泊6日プラン」「撮影&イベントプラン」など別プランの場合は期間が変わるので、その場合のバッファ計算もまず確認
