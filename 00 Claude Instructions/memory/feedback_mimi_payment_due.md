mi-mi+ 衣装レンタル請求書の **支払い期限 = 請求日（本日）から営業日 3 日後**。

土日祝（日本の祝日含む。GW・年末年始など）はカウントしない。

**Why:** ユーザから明示指定。レンタル開始日に合わせるのではなく、請求発行から 3 営業日というルール。

**How to apply:**
- 請求書作成時、請求日を当日にして支払い期限は営業日 3 日後を計算して入れる
- カウントの仕方: 当日は数えず、翌営業日を 1 日目とする
- 例: 2026/04/28（火）発行 → 4/29（昭和の日）スキップ → 4/30（1）, 5/1（2）, 5/2-6 は GW スキップ → 5/7（3）→ **支払期限 2026/05/07**
- 不確かな場合は祝日カレンダーを確認する（特に GW、お盆、年末年始、シルバーウィーク）
