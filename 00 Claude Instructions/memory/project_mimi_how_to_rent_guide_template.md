mi-mi+ 公式LINEで、友だち追加直後のお客様から「やり方がわからない」「上記の詳細を読んでもわからない」等の問い合わせが来た時の標準返信。**LINEのリッチメニューを開く操作を知らない初心者ユーザーが一定数いる**ため、メニュー使い方＋トーク内提出の2ルートを案内する。

## トリガー
- 友だち追加直後（友だち追加メッセージ受領後すぐ）の問い合わせ
- 「やり方がわからない」「メニューが見つからない」「申込方法がわからない」等のキーワード
- 既存のリッチメニュー誘導（メニュー左側／右側）が伝わっていない様子

## 返信テンプレ

```
○○様

はじめまして🙇
mi-mi+ 運営チームです🥺

ご連絡くださり、誠にありがとうございます！
ご案内がわかりづらく、大変申し訳ございません🙏

お申し込み方法を改めてご案内いたします💡

【方法①：リッチメニューから】
LINEトーク画面下部の「キーボード切替アイコン（▢のようなマーク）」をタップしますと、メニュー画像が開きます。
左側の【レンタルお申込】をタップしてご進行ください。

【方法②：このトークでお知らせいただく】
もしメニューが見当たらない場合は、下記をこのトークでお送りいただければ運営にてご案内いたします✨

① ご希望の衣装シリーズ（衣装リストよりお選びください）
② ご希望のレンタル日（受け取り日〜返却日）
③ お受け取り方法（郵送 or 中野アトリエ受け取り）
④ お名前・ご活動名／所属
⑤ ご連絡先（お電話番号・メールアドレス）
⑥ ご住所
⑦ お支払方法（クレジットカード or お振込）

ご不明点等ございましたら、お気軽にお知らせくださいませ。
引き続きどうぞよろしくお願いいたします🙏
mi-mi +
```
