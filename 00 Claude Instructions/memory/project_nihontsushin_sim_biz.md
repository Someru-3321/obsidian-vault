染める株式会社の日本通信SIM法人契約は **クレジットカード払い非対応**。支払い方法は口座振替 または 銀行振込のみ。

**Why:** 2026-04-22 にユーザーが法人窓口に「クレカ自動引き落とし対応可否」を問い合わせ。4月30日の返信で実質「クレカは対応していない、口座振替なら可能」という回答だった。2024-07-19 の規約変更で「原則口座振替」と明文化されており、月次の請求書案内メールにも「お支払いは口座振替での対応」と明記されている。

**How to apply:**
- 「日本通信SIM のクレカ払いに変更」依頼が来ても、対応不可と即答する（過去確認済み）。
- 支払い方法切替の希望が出たら、口座振替（毎月220円の振替手数料あり、2022年12月以降受領分から）を提案する。
- 口座振替手続き: https://www.nihontsushin.com/biz/change_information.html から「預金口座振替依頼書」DL → 記入・捺印 → 原本を日本通信宛に郵送。受領完了から1〜2ヶ月で切替反映。
- 現状（2026-05時点）は銀行振込で対応中。請求書PDFは法人ポータル経由でDL。

**関連情報:**
- 法人ポータル（お客様管理画面）: https://jpp.mvno.ne.jp/msp/login
- ログインID/PWは契約時案内メールに記載（Gmail内で見つからない可能性あり、その場合は窓口に再発行依頼）
- 法人窓口: msp@j-com.co.jp / Phone 03-6435-9430（請求催促）または 03-6701-8521（一般）平日09:00-18:00
- 振込先: 三井住友銀行 五反田支店 普通 1440488 日本通信株式会社
