「活動状況」select options（7つ・限定）:
- 活動中
- 活動休止
- 新グループに移行
- 無連絡
- オファー注意
- 活動終了
- オファーなし

「(AI作動)活動チェック」select options（より細かい・17）:
- 目視チェックOK / 目視チェック必要あり / メールアドレス間違い / 活動中 / 活動休止予定 / 活動休止 / 活動終了 / 更新停止（長期）/ 鍵アカ・閲覧不可 / 移行先あり / 告知のみ（稼働少）/ 存在しない / X URL間違い / 不明 / 女性アイドルグループではない / ソロ活動 / ユニット活動

aiCheck → status マッピング推奨:
- 活動中 → 活動中
- 活動休止 / 活動休止予定 → 活動休止
- 活動終了 / 更新停止（長期）→ 活動終了
- 移行先あり → 新グループに移行
- 存在しない / メールアドレス間違い / 鍵アカ・閲覧不可 / 告知のみ / 目視チェック必要あり / X URL間違い / 不明 / 女性アイドルグループではない → status はnullのまま（該当なし）
- 目視チェックOK → 活動中

**Why**: status は7択しかないため、aiCheck の細かい区分にぴったり対応するものが無いカテゴリー（存在しない・鍵アカ等）は status を空に保つ。誤って「活動終了」等にすると意味的な区別が失われる。
**How to apply**: バッチ更新時、aiCheck の値に応じてマッピングを参照し、null マッピングのレコードでは status を更新しない。
