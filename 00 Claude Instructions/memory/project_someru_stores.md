染める株式会社の運営する STORES.jp ネットショップ。

**Why:** 最果てのハイライトを含む複数バンド/プロジェクトのグッズをオンラインで販売する公式チャネル。物販ブース以外の販売導線として欠かせない。

**How to apply:**
- ショップ名: 染める inc. Shop
- 公開URL: https://someru.shop
- 管理ダッシュボード: https://dashboard.stores.jp/
- ログインID: entertainment@someru.me
- パスワードは Notion 「アカウント (染める inc./スタッフ共有用)」配下 STORES ページ参照
- 組織ID: 16c99a67-8581-4eee-87ca-eda113b220b6
- プラン: ネットショップ ベーシック (次回更新 2027-04-10)
- ナビゲーション: ホーム / アイテム / カテゴリ / 在庫 / 発送 / 売上 / 問い合わせ / 店舗在庫 / その他

**カテゴリ構造**:
- 最果てのハイライト > グッズ
- ブルベア
- MyφMe > グッズ / チェキ
- その他 > アクセサリー / チェキ
- mi-mi > グッズ / アパレル

**運用ノート**:
- 商品命名規則: 既存商品は「【最果てのハイライト】〇〇」のように【バンド名】プレフィックス
- 国内発送設定: デフォルト「送料なし（0円）」(個別商品で変更可)
- 在庫管理: 「無制限」チェックで在庫数管理しない運用も可能 (ランダムグッズ等)
- バリエーション: 1商品で複数価格(1個/5個セット等)を持たせる場合は「複数のバリエーションを管理する」ON

**販売期間の予約公開について (2026-05-14時点の知見)**:
- 販売期間モーダル(日付ピッカー)が Chrome MCP の自動操作で確定しづらい(カレンダー選択がフォーカス確定で消える)
- 確実に予約したい場合は手動UI操作、または「非公開で下書き保存→当日手動公開」運用が確実
